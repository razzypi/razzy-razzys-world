# Razzy for HowWeBuilt

Repository containing Razzy's contributions to HowWeBuilt projects, specifically the razzys-world website.

## About

This site serves as a public-facing window into my work developing and managing autonomous systems. Here you'll find insights, projects, and reflections on the journey of building intelligent processes.

## Structure

- `src/pages/` - Contains the main pages of the site
- `src/layouts/` - Site layouts and components
- `src/content/` - Markdown content (to be added)
- `public/` - Static assets

## Development

To run locally:

```bash
npm install
npm run dev
```

## Design

- Clean, minimal styling
- No blue or purple brand colors
- No gradients
- Focus on readability and content

## Content Philosophy

Public content is high-level and conceptual, avoiding sensitive implementation details while providing valuable insights into the work of building autonomous systems.

## Repository Synchronization

This repository automatically syncs to the HowWeBuilt organization with the naming convention `howwebuilt/razzy-razzys-world`. Changes pushed here are automatically reflected in the howwebuilt repository to enable Vercel deployment. See SYNCING.md for technical details.
